# Operation Quiet Guardian

Web presentation on Ajit Doval for a communication project: a declassified file laid over a live 3D night map of India (Three.js).

- `src/` holds the deck: `deck.css`, `deck.body.html` (markup), `deck.js` (slides, effects, 3D map).
- `mapdata.js` is the map grid and India outline, generated by `prep_map.py` style preprocessing.
- `python3 build.py` bundles everything into `dist/index.html` (open in Chrome or Edge) and `dist/deck.html` (preview build).

Keys: ← → or a clicker to move, F full screen, N speaker notes, M slide list.

Map data: India outline from DataMeet's `india-composite` (official boundary). Surrounding land from Natural Earth (public domain). City lights are drawn from city sizes, not satellite imagery.
